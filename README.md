# ✨ Ateliê Olhar – Design de Sobrancelhas

📌 Sobre o Projeto

O Ateliê Olhar é uma landing page desenvolvida para representar um espaço especializado em design de sobrancelhas e cuidados com a beleza. O projeto foi criado com o objetivo de apresentar os serviços oferecidos, transmitir profissionalismo e proporcionar uma experiência visual agradável, moderna e intuitiva para os visitantes.

A proposta é destacar a beleza natural de cada pessoa, valorizando a identidade visual do espaço por meio de um design delicado, elegante e organizado.

## 💡 Funcionalidades e Recursos

- 🏠 Página inicial: apresentação do Ateliê Olhar, com destaque para sua identidade e proposta de atendimento.
- 💖 Seção sobre: apresenta a filosofia do espaço, destacando o atendimento personalizado e o cuidado com cada cliente.
- ✨ Galeria de imagens: exposição de referências visuais relacionadas à beleza e aos cuidados com o olhar.
- 🧿 Seção de serviços: apresentação dos principais procedimentos disponíveis:
  - Design de sobrancelhas;
  - Design com henna;
  - Brow Lamination;
  - Coloração de fios;
  - Revitalização dos fios;
  - Combo olhar em destaque.
- 🌸 Experiência personalizada: destaque para o mapeamento individual, acolhimento e naturalidade dos resultados.
- ❓ Dúvidas frequentes: seção informativa para responder às principais perguntas dos clientes.
- 📲 Agendamento pelo WhatsApp: botões de contato para facilitar a comunicação e o agendamento de horários.
- 📍 Informações de atendimento: apresentação das informações relacionadas ao agendamento, localização e funcionamento.

## 🎨 Design e Experiência do Usuário

A interface foi desenvolvida com uma proposta visual sofisticada e delicada, buscando transmitir a identidade de um espaço especializado em beleza.

O projeto apresenta:
- Layout moderno e organizado;
- Imagens que valorizam a proposta estética;
- Seções bem distribuídas para facilitar a navegação;
- Elementos visuais delicados;
- Chamadas para ação que incentivam o contato;
- Experiência de navegação intuitiva.

O projeto foi desenvolvido com foco em proporcionar uma experiência agradável em diferentes dispositivos, buscando adaptar sua apresentação para computadores, tablets e smartphones.

## 🎯 Objetivo do Projeto

Este projeto faz parte da minha jornada de desenvolvimento Front-End e representa a aplicação prática dos conhecimentos adquiridos na criação de páginas profissionais para negócios.

A ideia foi desenvolver uma landing page que não apenas apresentasse os serviços de um espaço de beleza, mas também transmitisse confiança, cuidado e identidade visual, oferecendo aos visitantes um caminho simples até o agendamento.
